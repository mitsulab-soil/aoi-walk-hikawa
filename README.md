# Feel Hikawa（デモ版）

mitsulab の作品《Feel Hikawa》（フィール・ヒカワ）の**デモ版**です。場所ごとに世界を感じなおす「Feel site」シリーズの最初の一作で、案内役は AI の碧（あおい）です（旧名：碧と歩く　氷川）。試作中で、内容は予告なく変わります。

さいたま市大宮区の氷川参道を、実寸の 3D の中で歩きます。はじめに道を選びます。みじかい道は、二の鳥居をくぐって神社へ向かう並木の下（二の鳥居・ケヤキの根もと・三の鳥居・神池の 4 か所、およそ 500 m）。ながい道は、南の一の鳥居から平成ひろばをへて、同じ神池までの 6 か所（およそ 2 km）。
立ち止まった場所で、**みる → きく → かたる → かえりみる** の順に、同じ場所をもう一度見ます（mitsulab ではこの順番を「碧の間」と呼んでいます）。
碧（あおい）は mitsulab が AI で動かしている案内役です。確かめた事実を根拠に話し、断定せず、最後に問いを返します。

## 遊び方

- **画面で歩く**：どこからでも。はじめに「はじめる（音が出ます）」を押すと、碧の声が出ます（右上の「音」で消せます）。下の大きなボタン（→キー・スペース・吹き出しを左へスワイプでも）で進み、「‹」（←キー）で戻ります。「次の場所へ進む」で次の場所まで自動で歩きます。上の帯に、いまどこか（「2 / 4　ケヤキの根もとと縁」。分母は歩くあいだ変わりません）、下の帯に、いま何をするか（「いま：…」）が出ます。最後の神池のあとに「見方の記録」が出て終わります（画像で保存もできます。端末の中で作るだけです）。右上の「文字 大」で、字を大きくできます。
- **小さな謎**：場所ごとに一つ。選択肢を押して答えます（とばしてもかまいません。点数や順位はありません）。画面で歩くときは「近くで見る」で、対象に寄って見られます。
- **生きもの**：立ち止まる場所ごとに、その近くで iNaturalist に投稿された記録を 4 件まで（写真は CC0・CC BY・CC BY-SA だけ。その記録の写真が使えないときは「同じ種の参考写真」と明記。種のひとことは日本語版 Wikipedia の冒頭の一文で、学名で同じ種と確かめたものだけ）。記録は前もって受け取ったもので、ページを開いても iNaturalist へは取りに行きません。旧《氷川重奏》の生きものの層を、この作品に移しました。
- **土の中の手入れ**：氷川参道では、土中環境の改善の施工（しがら・点穴・素掘り溝など）が行われていて、mitsulab の代表も 2026 年 7 月から施工の現場に参加しています。
- **Qualia**：立ち止まる場所で、碧から Qualia（ほかの主体や系が世界をどう区切っているかの一部を、人が扱える形に写す道具）を一つずつ受け取ります。Chrono-Qualia（昔の空中写真）／Mechano-Qualia（3D 都市モデルの色分け・半透明）／Geo-Qualia（高さの強調・等高線）／Bio-Qualia（iNaturalist の記録・いきもの図鑑）／Logo-Qualia（典拠の言葉）／Hydro-Qualia（地形から求めた水の集まる線・見込み）。使うと、同じ参道が別の区切り方で現れます。Qualia ごとに、転写元・保つもの・変えるもの・移せないもの・確かさ（● 確立／◐ 一部・条件つき／○ 仮説）を示します。
- 謎を解くと印が、Qualia を受け取ると箱が埋まり、終わりに「見方の記録」が出ます（順位や点数はありません。記録は端末の中だけ）。
- **現地で歩く**：氷川参道で、スマホの位置情報を許可して始めます。歩いているあいだはスマホをポケットに入れ、合図（振動・音）があったら、**安全な場所で立ち止まってから**取り出してください。歩きながら画面を見ないでください。車道・横断歩道・自転車の通る帯・参拝の妨げになる場所では立ち止まらないでください。
- 見方の記録は、お使いの端末の中だけに残ります。このデモ版では、碧とは用意した問いを選んで話し、会話はどこにも送られません（mitsulab も保存しません）。
- 歩き終えると、次にできること（現地で歩く・ほかの道具・知らせを受け取る）が出ます。
