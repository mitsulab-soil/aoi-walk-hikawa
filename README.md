# Feel Hikawa（デモ版）

mitsulab の作品《Feel Hikawa》（フィール・ヒカワ）の**デモ版**です。場所ごとに世界を感じなおす「Feel site」シリーズの最初の一作で、案内役は AI の碧（あおい）です（旧名：碧と歩く　氷川）。試作中で、内容は予告なく変わります。

さいたま市大宮区の氷川参道を、実寸の 3D の中で歩きます。**碧が右隣を歩き、いまいる場所の話を声でします。**画面に出る文字は、碧が話している文（下の字幕）だけです。
碧（あおい）は mitsulab が AI で動かしている案内役です。確かめた事実（出典はメニューの中）だけを話し、推測は「とみられます」、伝承は「伝えられます」と言います。木や土や場所の良し悪しは診断しません。お店はすすめません。

## 遊び方（2026-10-04 作り直し 第1回）

- はじめに、**聞きたい話**を選びます：歴史・文化・自然・生き物・土・お店（いくつでも。最初は歴史・自然・生き物）。途中で変えると、次の話から変わります（左上の ≡ メニュー）。
- **画面で歩く**：参道を自動で歩きます。碧は話す場所に来ると立ち止まり、こちらを向いて話します。押して進める操作はありません。下の帯の「もう一度」で聞き直し、「とばす」で次へ、「止まる」で歩くのを止めます。画面をドラッグすると見回せます。
- **上の小さな地図**：参道の全体（一の鳥居〜神社）と、いまの位置・向き。押すと、その場所へ移ります（「広げる」で大きく）。
- **現地で歩く**：氷川参道で、位置情報を許可して始めます。位置に合わせて碧が話します。**歩きながら画面を見ないでください**（イヤホンで、耳で聞いてください）。横断歩道とその前後では碧は話さず、手前で渡るときの注意だけを伝えます。車道の並ぶ区間（南区間・北区間）は、2026 年 10 月 26 日に歩行者専用になってから話します。境内では、イヤホンが無いときは声を止め、字幕だけにします。
- **生き物**：参道の近くで iNaturalist に投稿された記録（研究等級のもの）の名前だけを言います（いまそこにいる、とは言いません）。
- **土**：氷川参道では、並木の土の中の環境を整える施工（しがら・点穴・素掘り溝など）が行われていて、mitsulab の代表も 2026 年 7 月から施工の現場に参加しています。
- **お店**：OpenStreetMap に記録されているお店の名前と区分だけを言います（感想・おすすめは言いません。閉じている店があるかもしれません）。
- 位置は端末の中だけで使い、送らず、残しません。選んだ話・音・文字の大きさだけを、この端末に覚えます。会話はありません（碧へ何かを送ることはありません）。
