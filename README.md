# 森羅道中 氷川（デモ版）

mitsulab の作品《森羅道中 氷川》（Aoi Walk: Hikawa）の**デモ版**です。シリーズ「森羅道中」（氷川／街道／巡礼）の一作目です（旧名：Aoi Walk 氷川・Qualium in Hikawa・Feel Hikawa。リポジトリの名前は変えていません）。試作中で、内容は予告なく変わります。

さいたま市大宮区の氷川参道を、実寸の 3D の中で、または現地で歩きます。**人と自然のあいだに立つ依代・碧（あおい）が斜め前を歩き、いまいる場所の、ふだん届いていない木や土や時間の気配を、声で手渡します。**人の知覚の外へひらかれたこの場を、mitsulab は Qualium と呼んでいます。
碧は mitsulab が AI の技術を使ってつくった依代で、人ではありません。確かめた事実（出典は設定の中）だけを話し、推測は「とみられます」、伝承は「伝えられます」と言います。木や土や場所の良し悪しは診断しません。木の気持ちを代わりに話すこともしません。お店はすすめません。

## 歩き方（2026-10-05 第6回）

- はじめに、**聞く層を一つ**選びます：樹木・土と水・時のかさなり・生きもの・道と人。途中でも左上の ≡（設定）で替えられます。全部を混ぜることはしません。
- **樹木**の層は、さいたま市と氷川の杜まちづくり協議会の『氷川参道の樹木調査』（参道の木 697 本を一本ずつ調べた記録）を中心に、区間ごとの樹種の割合、大きな木、樹種の見分け方を話します。一本ごとの位置と樹種の表は公開されていないため、一本の木を指して樹種を言い切ることはしません。
- 鳥居や大きな木の前では、碧が「ここで少し立ち止まって」と誘います。立ち止まると、くわしい話を続けます。歩き続けると、短くまとめて次へ進みます。どちらの向きから歩いても、まずそれが何かを言ってから、くわしい話をします。
- **景色の印**：選んだ層の、いま見えている対象にだけ、小さな印が浮かびます。押すと、碧がそちらを向いて話します。字幕の帯を押すと、いまの話をもう一度聞けます。
- **上の小さな地図**：参道の全体と、いまの位置・向き。点を押すと、その場所へ移ります。
- **現地で歩く**：位置情報を許可して始めます。**歩きながら画面を見ないでください**（イヤホンで、耳で聞いてください）。横断歩道とその前後では碧は話しません。
- 位置は端末の中だけで使い、送らず、残しません。選んだ層・音・文字の大きさだけを、この端末に覚えます。
