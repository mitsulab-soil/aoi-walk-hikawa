# 碧と歩く　氷川（デモ版）

mitsulab の作品《碧と歩く　氷川》の**デモ版**です。試作中で、内容は予告なく変わります。

さいたま市大宮区の氷川参道（一の鳥居〜神池、約 1.9 km）を、実寸の 3D の中で歩きます。
六つの場所で立ち止まり、**みる → きく → かたる → かえりみる**（碧の間）の順に、同じ場所をもう一度見ます。
碧（あお）は mitsulab の AI の語り手です。確かめた事実だけを語り、断定せず、最後に問いを返します。

## 遊び方

- **画面で歩く**：どこからでも。下の目盛りで参道を進みます。
- **現地で歩く**：氷川参道で、スマホの位置情報を許可して始めます。歩いているあいだはスマホをポケットに入れ、合図（振動・音）があったら、**安全な場所で立ち止まってから**取り出してください。歩きながら画面を見ないでください。車道・横断歩道・自転車の通る帯・参拝の妨げになる場所では立ち止まらないでください。
- 見方の記録は、お使いの端末の中だけに残ります。このデモ版では、碧との会話は用意した答えで進み、外へ送られません。
