# Qualium in Hikawa（デモ版）

mitsulab の作品《Qualium in Hikawa》（クオリウム・イン・ヒカワ）の**デモ版**です。案内役は AI の碧（あおい）です（旧名：Feel Hikawa・碧と歩く　氷川。リポジトリの名前は変えていません）。試作中で、内容は予告なく変わります。

さいたま市大宮区の氷川参道を、実寸の 3D の中で歩きます。**碧が斜め前を歩き、いまいる場所の話を声でします。**画面に出る文字は、碧が話している文（下の字幕）と、選んだ話の小さな印だけです。
碧（あおい）は mitsulab が AI で動かしている案内役です。確かめた事実（出典はメニューの中）だけを話し、推測は「とみられます」、伝承は「伝えられます」と言います。木や土や場所の良し悪しは診断しません。木の気持ちを代わりに話すこともしません。お店はすすめません。

## 遊び方（2026-10-04 第3回）

- はじめに、**聞く話を一つ**選びます：樹木・土と水・時のかさなり・生きもの・道と人（最初は樹木）。途中でも左上の ≡ メニューで替えられます。全部を混ぜることはしません。
- **樹木**の話は、さいたま市と氷川の杜まちづくり協議会の『氷川参道の樹木調査』（2002〜2010 年に参道の木 697 本を一本ずつ調べた記録）を中心に、区間ごとの樹種の割合、木の大きさ、並木の課題、樹種の見分け方を話します。一本の木を指して樹種を言い切ることはしません（一本ごとの位置と樹種の表は公開されていないため）。
- **画面で歩く**：参道を自動で、ふつうの速さで歩きます。北へも南へも歩けます（はじめの画面か、メニューで）。鳥居や石碑は、前に見えてきたときに、まずそれが何かを言ってから、くわしい話をします。右手・左手は、歩いている向きに合わせて言います。
- **景色の印**：選んだ話の対象に、小さな印が浮かびます。押すと、碧がそちらを向いて、その話（聞いた後なら、くわしい話）をします。
- **上の小さな地図**：参道の全体と、いまの位置・向き。七つの点を押すと、その場所へ移ります（「広げる」で大きく）。
- **現地で歩く**：氷川参道で、位置情報を許可して始めます。位置は少しずれることがあるので、参道の歩ける所（歩道・石の道など）に合わせて、なめらかにしています。**歩きながら画面を見ないでください**（イヤホンで、耳で聞いてください）。横断歩道とその前後では碧は話さず、手前で渡るときの注意だけを伝えます。車道の並ぶ区間（南区間・北区間）は、2026 年 10 月 26 日に歩行者専用になってから話します。境内では、イヤホンが無いときは声を止め、字幕だけにします。
- 位置は端末の中だけで使い、送らず、残しません。選んだ話・音・文字の大きさだけを、この端末に覚えます。会話はありません（碧へ何かを送ることはありません）。
